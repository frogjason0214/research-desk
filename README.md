# Research Desk

心理學研究輔助桌面工具（Windows）。目前完成第一階段（右側常駐邊欄、研究專案、論文里程碑與口試倒數、待辦清單、跨電腦同步、Google 行事曆、安裝檔與自動更新）、第二階段（文獻整理）、第三階段（心智圖）、第四階段（AI 教授），以及簡易版 Notion 的「筆記」。

## 安裝（給同學）

1. 到 https://github.com/frogjason0214/research-desk/releases 下載最新的 `ResearchDesk-Setup-x.y.z.exe` 並執行。
2. 安裝檔沒有數位簽章，Windows 會跳出「Windows 已保護您的電腦」：按「其他資訊」→「仍要執行」。
3. 之後有新版本時，程式會自動在背景下載，提示「重新啟動」即可更新。
4. 要使用 Google 行事曆，請先把你的 Gmail 告訴開發者，加入測試使用者名單。

## Mac 測試版

- 到 Releases 找「Mac 測試版」（預先發行版）：Apple 晶片（M1 以後）下載 `…-mac-arm64.dmg`，Intel Mac 下載 `…-mac-x64.dmg`。
- 沒有 Apple 簽章：第一次打開時在 Finder 對程式按右鍵 →「打開」；被擋下時到「系統設定 → 隱私權與安全性」最下面按「強制打開」。
- 只存在這台電腦，不支援跨電腦同步；Windows 與 Mac 的資料各自獨立（Google 行事曆兩邊都能用）。
- 不會自動更新，新版請到 Releases 下載。
- 一篇文獻連到多個節點時，Mac 只在第一個節點的資料夾放檔案，其他節點不放捷徑。
- 建置：`.github/workflows/mac.yml` 在每次 Windows 版發布（`v*` 標籤）時自動執行，也可以在 GitHub 的 Actions 頁面手動執行。Google 行事曆的用戶端放在 repo 的 Secrets（`GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`）。

## 發布新版本（開發者）

1. 把 `package.json` 的 `version` 往上加（例如 0.1.0 → 0.2.0），commit 並 push。
2. 在終端機設定 GitHub 權杖後執行 `npm run release`（權杖需要該 repo 的 Contents 讀寫權限）：

   ```
   $env:GH_TOKEN="github_pat_..."; npm run release
   ```

3. 已安裝的人下次開程式時會自動更新。

## 從原始碼執行（開發者，約 10 分鐘）

1. 到 https://nodejs.org 下載並安裝 **LTS 版本** 的 Node.js，安裝過程一路按「下一步」即可。
2. 把這個資料夾解壓縮到容易找的地方，例如 `文件\research-desk`。
3. 打開該資料夾，在空白處按右鍵 →「在終端機中開啟」（Windows 11）。Windows 10 可在資料夾網址列輸入 `powershell` 後按 Enter。
4. 輸入下列指令並按 Enter，第一次會下載套件，需要幾分鐘：

   ```
   npm install
   ```

5. 啟動程式：

   ```
   npm run dev
   ```

6. 第一次啟動不用做任何設定，資料會先存在這台電腦。想在多台電腦使用，再到「設定」開啟跨電腦同步。

之後每次要用，只要在同一個資料夾執行 `npm run dev`。只打包、不發布用 `npm run dist`，安裝檔會在 `dist\`。

## 怎麼用

- 螢幕右側中段有一小條（約螢幕高度的 1/5），上面是距離學位口試的天數。滑鼠移過去就會展開邊欄，移開會自動收合；展開後按頂端的 ⋮⋮ 可以上下拖曳位置。打開完整視窗時這一條會先藏起來，完整視窗關掉或最小化時再回到右側。
- 完整視窗左側六個入口：
  - **今天**：上方是口試倒數與里程碑進度（點一下可編輯里程碑）；左邊行事曆、右邊 AI 本日建議與待辦。把待辦拖到行事曆的日期上就能設定截止日；行事曆上的待辦依狀態上色（逾期紅、今天橘、之後綠、完成灰），Google 行程統一淡藍色。沒登入 Google 也能用，只顯示待辦。
  - **文獻**：匯入 PDF（選檔或直接拖進頁面）或貼上網址加入網頁。英文文獻以 DOI 向 CrossRef 查書目；中文或沒有 DOI 的由 Gemini 判讀並標示「待確認」。可一鍵複製 APA 第 7 版參考文獻與文中引用（貼到 Word 保留斜體）。研究類型、樣本、量表、主要發現由 AI 預填；勾「不送 AI」的文獻或筆記永遠不會送出。篩選框按 Enter 可搜尋全文。
    - PDF 閱讀器：在文獻按「閱讀」，整頁換成閱讀器（左上角返回）。螢光筆有黃綠藍粉四色，選取文字就畫上；也可以框選一塊區域（掃描版 PDF、表格、圖）。便利貼可以放在頁面任何地方，螢光筆也能加註解。點重點可以換顏色、寫註解、刪除；Ctrl+Z 復原；Ctrl+F 搜尋這篇；下次打開回到上次讀到的頁。
    - Google 翻譯：用「選取」工具選一段文字，旁邊會出現「翻譯」按鈕，按下去顯示中文翻譯（選中文會翻成英文），可以複製。要先在「設定 → Google 翻譯」填入 Google Cloud Translation API 金鑰（每月前 50 萬字免費），每台電腦各自設定；翻譯只顯示，不存進 PDF。
    - 重點直接寫回文獻原本的 PDF（標準 PDF 註記），用 Acrobat、預覽程式、瀏覽器打開也看得到；中文註解也沒問題。停下來約 1 秒就自動存檔。
    - 第一次在一篇文獻畫重點前，原檔會備份到「文獻」裡的隱藏資料夾 `.原始檔`，閱讀器的「還原」按鈕可以換回原檔。
    - 兩台電腦都在同一篇畫重點時，存檔前會重新讀檔，以一個註記為單位合併，兩邊的重點都會留下。PDF 正被 Acrobat 等程式開著時會顯示提示，關掉後自動存檔；還沒存進去的修改不會因為關掉程式而遺失。
    - 其他程式畫的螢光筆、底線、便利貼看得到也可以刪除（刪除前會再確認一次），但不能修改；手寫、文字框等其他種類只會顯示。加密的 PDF 只能閱讀。
  - **心智圖**：每個專案可以有多張圖。選節點後直接打字就能改名（注音、拼音都可以），Tab 新增子節點、Enter 新增同層、F2 或雙擊改名、Delete 刪除、空白鍵收合；拖曳父節點時子節點一起移動。工具列的連結圖示打開側欄，可以連結文獻、從節點新增待辦、匯入 PDF 或網址；也可以把 PDF 從檔案總管直接拖到節點上，匯入後自動連到那個節點。整理圖示可一鍵排成向右樹狀或左右平衡。
    - 畫筆（黑紅藍綠、細／粗）、橡皮擦（一次擦掉整條）、便利貼（點一下放置，上方橫條拖曳搬動，右下角調寬度）。筆跡與便利貼固定在畫布上，不跟著節點移動；Ctrl+Z 復原，Esc 回到選取。匯出圖片時一起印出。
  - **筆記**：像 Notion 的頁面樹，頁面可以有子頁，拖曳可以換順序（拖到頁面中間變成子頁）。內容支援標題、清單、引言、程式碼、分隔線、表格、圖片（直接貼上或拖進來）；打 `/` 叫出插入選單，`# `、`- `、`1. `、`> ` 等 Markdown 快捷也能用；打 `@` 引用文獻，點引用會打開那篇。刪除的頁面先進垃圾桶，30 天後才永久刪除。
    - 匯入 .md：「頁面」旁的匯入圖示可一次選多個檔，每個檔變成一頁；第一行的 `# 標題` 當頁面名稱，檔案裡引用的本機圖片會一起複製進來。
    - 匯出 .md：頁面右上角的匯出圖示，存成一個 .md，圖片放在旁邊的「<檔名> 附件」資料夾。只匯出這一頁，不含子頁；`@` 引用匯出成文字（例如 (Ioannidis, 2005)）。
  - **AI 教授**：開新對話時選角色（研究方向與缺口、研究方法與統計、模擬口試委員、一般討論）。回答裡的 [P1]、[S2] 標記可以點開對應的文獻。「推薦新文獻」只列出 OpenAlex 查得到、有 DOI 的真實論文。
  - **設定**：專案名稱、論文里程碑、跨電腦同步、Google 行事曆、AI 金鑰、Google 翻譯金鑰、開機自動啟動。
- 有截止日的待辦會自動同步到 Google 的「研究任務」行事曆（App 裡的行事曆不重複顯示這個行事曆）。

## 資料存在哪裡

每個人的資料只存在自己的電腦或自己的雲端硬碟，不需要登入任何帳號。

- **預設**：存在這台電腦（`%APPDATA%\research-desk\library\`）。
- **跨電腦同步**：在「設定 → 資料與跨電腦同步」點選偵測到的 OneDrive／Google Drive／Dropbox（或「其他資料夾…」），程式會建立 `ResearchDesk` 資料夾並把資料搬過去，**之後這台電腦不再另存一份**。另一台電腦在設定裡選同一個雲端硬碟就能加入。
- 兩台電腦可以同時開著、同時編輯，不會被鎖成唯讀。

| 位置 | 內容 |
| --- | --- |
| `ResearchDesk\changes\<裝置編號>.jsonl` | 每台電腦各自的變更紀錄，只有那台電腦會寫入 |
| `ResearchDesk\文獻\<專案>\<心智圖>\<節點>\…` | 文獻檔案依心智圖節點分資料夾，檔名「作者 年份 篇名」；一篇連到多個節點時，其他節點放捷徑 |
| `ResearchDesk\文獻\<專案>\未分類\` | 還沒連到節點的文獻 |
| `ResearchDesk\文獻\<專案>\全文\` | 所有抽出的全文 `.txt` |
| `ResearchDesk\筆記\<專案>\<頁面>.md` | 筆記的 Markdown 副本；子頁放在上層頁面同名的資料夾裡（唯讀副本，在外面修改不會回寫） |
| `ResearchDesk\筆記\附件\` | 筆記裡的圖片 |

讀取時合併所有電腦的紀錄；兩台改到同一筆資料時以欄位為單位，最後修改的為準（筆記以段落、表格等區塊為單位，兩台同時改同一頁的不同段落都會留下）（用邏輯時鐘判斷，電腦時間不準也不影響）。因為每個檔案只有一台電腦寫入，雲端硬碟不會產生衝突副本。

- 雲端資料夾暫時找不到（OneDrive 登出、資料夾被搬走）時，新的修改先暫存在本機 `pending.jsonl`，恢復後自動搬過去並刪除暫存。
- 專案、心智圖、節點改名時，資料夾整個跟著改名（你自己放進去的檔案也一起搬）；程式只會清掉空的資料夾，不會刪除任何檔案。
- 筆記的 .md 副本只會更新或刪除程式自己產生的檔案（第一行有標記），你自己放進「筆記」資料夾的檔案不會被動到。
- 捷徑（.lnk）記錄的是這台電腦上的完整路徑；兩台電腦的 OneDrive 路徑不同時，會在整理時各自更新。
- 加入同步時，若雲端和這台電腦都有資料，會詢問要「合併」或「改用雲端的資料」（本機資料另存在 `library-backup-…` 備份資料夾）。
- 停止同步時，最新資料與檔案會複製回這台電腦，雲端那份不動。
- 舊版的 `research-desk.sqlite` 會在第一次啟動時自動轉換，舊檔改名為 `research-desk.sqlite.bak`。請把每台電腦都更新到新版，舊版程式不認得新格式。

## 程式結構

```
src/
  main/       主程式：視窗、變更紀錄與同步（library）、查詢快取（store）、處理畫面的請求
  preload/    畫面與主程式之間的安全橋接
  shared/     共用型別與里程碑範本
  renderer/   畫面（React）
    views/      邊欄 Sidebar、完整視窗 FullWindow
    components/ 倒數、待辦列、新增待辦等元件
```

想修改里程碑範本，編輯 `src/shared/types.ts` 最下方的 `MILESTONE_TEMPLATE`。

## 技術選擇備註

- 查詢使用 sql.js（WebAssembly 版 SQLite）的記憶體資料庫，由變更紀錄算出，不需要在 Windows 安裝 C++ 編譯工具。
- 寫進雲端的檔案都先寫暫存檔再改名，避免雲端硬碟同步到一半的檔案。
- 每 20 秒檢查一次其他電腦的修改；自己的修改約 2 秒後寫進雲端。
- 自動化測試用的環境變數：`RESEARCH_DESK_USER_DATA`（資料夾）、`RESEARCH_DESK_EXPORT_PATH`（心智圖匯出不跳視窗）、`RESEARCH_DESK_GEMINI_API`（改連模擬的 Gemini 伺服器）。

## Google 行事曆設定（開發者，只需一次）

1. Google Cloud Console 建立專案，啟用 Google Calendar API。
2. Google Auth Platform → 開始：目標對象選「外部」；在「目標對象 → 測試使用者」加入自己與同學的 Gmail（測試模式上限 100 人）。
3. Google Auth Platform → 用戶端 → 建立用戶端 →「電腦版應用程式」。
4. 把 `.env.example` 複製成 `.env`，填入用戶端 ID 與密碼，重新執行 `npm run dev` 或重新建置。

- 登入時權限畫面要勾選行事曆權限；沒勾的話 App 會提示重新登入。
- 測試模式的登入約 7 天過期，App 會在邊欄與完整視窗提示重新登入。
- 登入憑證以 Windows DPAPI 加密，只存在這台電腦（`google-token.bin`）；每台電腦各自登入。
- 待辦事件的 ID 由待辦 ID 算出（`rdt` + UUID），兩台電腦同時推送也只有一個事件。
